# Report Definitions

## Member Register

Purpose: Shows all registered SACCO members.

Columns:

- Member number
- Full name
- Gender
- ID number
- Phone
- Branch
- Date joined
- Status

Filters:

- Branch
- Status
- Date joined range

## Account Balance Report

Purpose: Shows current balances by member account.

Columns:

- Account number
- Member number
- Member name
- Account type
- Product
- Current balance
- Status

Filters:

- Branch
- Account type
- Product
- Status

## Savings Statement

Purpose: Shows a member account transaction history.

Columns:

- Transaction date
- Transaction type
- Payment method
- Amount
- Balance after
- Narration
- Posted by

Filters:

- Account
- Date range
- Transaction type

## Daily Teller Collection Report

Purpose: Shows money received or paid by each teller in a day.

Columns:

- Teller
- Transaction type
- Payment method
- Number of transactions
- Total amount

Filters:

- Date
- Branch
- Teller
- Payment method

## Loan Portfolio Report

Purpose: Shows loan balances and statuses.

Columns:

- Loan number
- Member number
- Member name
- Loan type
- Loan amount
- Interest rate
- Repayment period
- Total repaid
- Outstanding balance
- Status

Filters:

- Branch
- Loan type
- Product
- Status
- Date range

## Loan Arrears Report

Purpose: Shows loans with overdue repayments.

Columns:

- Loan number
- Member number
- Member name
- Phone
- Loan amount
- Expected installment
- Amount paid
- Outstanding balance
- Days overdue
- Status

Filters:

- Branch
- Loan type
- Days overdue
- Status

## Repayment Report

Purpose: Shows loan repayments received.

Columns:

- Repayment date
- Loan number
- Member name
- Installment number
- Amount paid
- Principal
- Interest
- Balance outstanding
- Payment method
- Received by

Filters:

- Date range
- Branch
- Loan type
- Payment method
- Received by

## Branch Performance Report

Purpose: Compares SACCO activity by branch.

Columns:

- Branch
- Active members
- Total savings
- Total welfare contributions
- Total share capital
- Active loans
- Total loan amount
- Total repayments
- Outstanding loan balance

Filters:

- Date range
- Branch
